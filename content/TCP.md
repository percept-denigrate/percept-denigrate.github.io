TCP (transport control protocol) is a layer 4 protocol used to transmit data.

It ensures that all data sent is received, and that it is received in the correct order.

It uses ports to allow for multiple programs to use tcp on a single machine. Commonly used ports:

- 20: [[FTP]] data transfer
- 21: [[FTP]] control
- 22: [[SSH]]
- 25: SMTP
- 23: Telnet
- 53: [[DNS]]
- 80: [[HTTP]]
- 88: [[Kerberos]] authentication
- 443: [[HTTP|HTTPS]]
- 3306: [[MYSQL]]
- 8080: proxies
